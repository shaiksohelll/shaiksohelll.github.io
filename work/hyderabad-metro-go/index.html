03Selected system

Hyderabad Metro Go.

A client-side Hyderabad route planner modelling three lines and computing fewest-stop paths with a deque-based 0-1 BFS.

Live system · GitHub Pages

Vanilla JavaScript · HTML5 · CSS3 · Bootstrap 5

Definition

The route is computed.

The graph stores station-on-line nodes. Ride edges cost one stop, interchange edges cost zero, and the deque-based 0-1 BFS returns the shortest stop-count path while preserving actual interchange details.

The UI also includes fare slabs, estimated distance/time, station facilities and parking presets, travel tips, and recent-trip persistence in localStorage under hmg_recent.
