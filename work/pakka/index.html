Definition

The ledger has rules.

The SQL source recreates four SECURITY DEFINER escrow RPCs with authorization and milestone-state guards. Partial unique indexes protect fund/release ledger rows and one open dispute per milestone; the source also uses row locks and transaction rollback as money-mutation safeguards.

Idempotency is operation-specific rather than one universal key: funding uses the caller-supplied key, while submit/approve/dispute rely on status, milestone, ledger, or open-dispute guards. This page keeps that distinction explicit.
