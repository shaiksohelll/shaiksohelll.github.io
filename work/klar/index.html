01Selected system

Klar.

A job-market analytics platform ingesting from Adzuna and JSearch, then surfacing skills, salary, company, and trend views.

Live system · Open source

React client · Express server · MongoDB

Definition

The system collects signal.

The active server wires Express with Helmet, CORS, rate limiting, Clerk, Sentry, and separate Adzuna/JSearch ingestion modules. JSearch is swept across six role queries with a 1.2-second inter-request delay and a 10-second abort timeout; writes are bulk-upserted and partial snapshots are guarded from destructive pruning.

The history layer records day-bucketed skill-flow rows. The earlier capturedAt momentum path is legacy and is not presented here as active.
